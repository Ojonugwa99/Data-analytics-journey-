# Day 03 — Formulas and Functions

## What I Learned

* Formulas
* Functions
* Logical Functions
* IF function
* AND function
* OR function
* NOT function

## Formulas

Learned how to create formulas using cell references and basic arithmetic operators such as:

* Addition `+`
* Subtraction `-`
* Multiplication `*`
* Division `/`

## Functions

Learned how Excel's built-in functions can perform calculations more efficiently.

Practiced functions such as:

* SUM
* AVERAGE
* COUNT

## Logical Functions

Learned how Excel can evaluate conditions and return different results based on whether a condition is TRUE or FALSE.

Practiced the IF function and explored logical functions such as AND, OR and NOT.
